# 7-Day Practical Study Plan

## Day 1: Architecture And Business Process

- Understand the onboarding business scenario.
- Read `docs/architecture.md`.
- Draw or update an architecture diagram.
- Write the BPMN process in `docs/bpmn.md`.

## Day 2: Database And API

- Study `database/migrations/001_init.sql`.
- Run PostgreSQL locally.
- Implement or test `POST /employees`.
- Practice SQL selects, inserts, updates, joins, and constraints.

## Day 3: Webhooks And Integration Reliability

- Test `POST /webhooks/workato/onboarding-approved`.
- Add failed integration examples.
- Practice idempotency, retry logic, and error logging.

## Day 4: Workato Concepts

- Read the recipe specs in `workato/recipes`.
- Learn triggers, actions, conditions, data mapping, and error handling.
- Explain how Workato connects SharePoint, Salesforce, Zuora, and custom APIs.

## Day 5: SharePoint And Power Automate

- Read SharePoint list designs.
- Build mock list columns.
- Design Power Automate approval flow.
- Practice explaining SharePoint Pages, Web Parts, and site structure.

## Day 6: MCP And AI Agent

- Read `mcp/README.md` and `ai-agent/README.md`.
- Expose business actions as tools.
- Use AI to summarize failed integration runs and draft support messages.

## Day 7: Interview And Test Task Prep

- Read `docs/interview-notes.md`.
- Run the demo end-to-end.
- Prepare a 2-minute explanation of the project.
- Practice one test task: build a webhook endpoint with validation and logging.
